# Line Editor

## Team Project

A simple line editor developed in C.

## Features

- Insert a line
- Delete a line
- Display the document
- Save the document
- Exit the program

## How to Run

Compile the program:

gcc line_editor.c -o line_editor

Run the program:

line_editor.exe

## Files

- `line_editor.c` – Main C source code
- `document.txt` – Saved document
- `HELP.md` – User help and commands
- `README.md` – Project information
